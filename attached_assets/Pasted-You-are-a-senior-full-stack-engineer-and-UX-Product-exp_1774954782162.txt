You are a senior full-stack engineer and UX/Product expert (ex-Facebook / Instagram level).

Your task is to **REBUILD the user profile system** with a professional and modern approach, unifying URLs and enhancing all profile features.

========================

1. UNIFIED PROFILE URL SYSTEM
   ========================

* Every user (basic or professional/chef) has **one unique username**.
* Profile URL format:
  https://tabaq.co/:username
* No additional slugs like `/chefs/` or `/user/`
* Routing should automatically detect account type and display appropriate profile
* Clicking any username anywhere opens `/username`

========================
2. ACCOUNT TYPES (DISPLAY DIFFERENCE)
=====================================

* Basic user:

  * Profile photo, username, bio, visits, reviews, favorites
  * Account type label: “Basic User”
* Professional user / Chef:

  * All basic features PLUS:

    * Extended bio & experience
    * Dishes showcase
    * Orders/request dishes UI
    * Professional dashboard with stats (followers, ratings, reviews)
  * Account type label: “Professional / Chef”
* Upgrade system: Allow users to upgrade from Basic → Professional with account type change reflected on profile

========================
3. PROFILE UI & FEATURES
========================

* **Header**: Cover image, profile photo, username, account type label, bio, social links
* **Stats section**: Followers, Following, Visits, Reviews
* **Tabs/Sections**:

  * Overview
  * Visits
  * Reviews
  * Favorites
  * Dishes (for professionals)
  * Plans
  * Recommendations
* **Buttons**:

  * Follow / Unfollow
  * Share profile
  * Quick actions (Message, Order dish if chef)
* **Stories section**:

  * Show user-uploaded stories (images/videos)
  * Auto-expire after 24h
  * View in carousel style
* **Enhanced menu**:

  * Organized dropdown for settings, editing, logout

========================
4. PRIVACY & VISIBILITY
=======================

* Full control over:

  * Who can view profile (Public / Followers / Private)
  * Who can see visits, reviews, favorites, plans
* Editable in **Profile Settings**
* Account-level differentiation: Professional accounts can enable “public showcase” mode
